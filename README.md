## 🎯 Funcionalidades

- ✅ **CRUD Completo** — Crie, edite, conclua e exclua tarefas
- 🏷️ **Prioridades & Tags** — Alta, Média, Baixa com cores distintas
- 📅 **Datas de Vencimento** — Alertas visuais para tarefas atrasadas
- 🔍 **Filtros Inteligentes** — Todas, Ativas, Concluídas, por Prioridade
- 🌓 **Dark/Light Mode** — Toggle suave entre temas
- 🖱️ **Drag & Drop** — Reordene tarefas com SortableJS
- ⌨️ **Atalhos de Teclado** — `N` nova tarefa, `Esc` fechar modal, `Enter` salvar
- 📊 **Barra de Progresso** — Acompanhe seu desempenho em tempo real
- 💾 **Persistência Local** — Dados salvos no localStorage
- 📤 **Exportar/Importar JSON** — Backup e restore das suas tarefas

---

## 🚀 Como usar

1. Clone o repositório:
   ```bash
   git clone https://github.com/gustavodeoliveiradev/taskflow.git
   cd taskflow
   ```

2. Abra o `index.html` no navegador:
   ```bash
   # Ou simplesmente dê duplo-clique no arquivo
   # Ou use um servidor local:
   npx serve .
   ```

3. Comece a organizar suas tarefas! 🎉

## 🛠️ Tecnologias

| Tecnologia | Uso |
|------------|-----|
| **HTML5 Semântico** | Estrutura acessível e SEO-friendly |
| **CSS3 (Grid + Flexbox)** | Layouts responsivos e modernos |
| **CSS Variables** | Design tokens e temas dinâmicos |
| **Vanilla JavaScript ES6+** | Lógica 100% modular com classes |
| **SortableJS** | Drag-and-drop fluido e animado |
| **localStorage API** | Persistência de dados no navegador |
